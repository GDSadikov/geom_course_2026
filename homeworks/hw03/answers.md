# Ответы на вопросы ДЗ №3

**1. Почему для изменения давления во времени используется линейный график?**

Время — упорядоченная непрерывная величина. Линейный график позволяет проследить изменение давления и увидеть общую динамику процесса.

**2. Почему для наблюдательных скважин используется точечная диаграмма, а не линейный график?**

Скважины являются отдельными объектами, расположенными на разных расстояниях. Соединение точек линиями могло бы создать ложное впечатление непрерывного изменения давления между ними.

**3. Для чего используется столбчатая диаграмма?**

Она позволяет сравнивать отдельные значения между категориями. В данном задании с её помощью сравнивается падение давления в разных скважинах.

**4. Что показывает boxplot (диаграмма размаха)?**

Она показывает распределение данных: медиану, нижний и верхний квартили, разброс значений и возможные выбросы.

**5. Чем violinplot отличается от boxplot?**

Violinplot дополнительно показывает форму распределения и плотность значений. Boxplot более наглядно отображает основные статистические характеристики.

**6. Почему для этих данных не подходит круговая диаграмма?**

Круговая диаграмма предназначена для отображения частей единого целого. Значения давления являются отдельными измерениями, а не долями общей величины.
